EDA CLI - Инструмент для анализа данных
  Описание проекта
EDA CLI (Exploratory Data Analysis Command Line Interface) - это инструмент для быстрого анализа CSV файлов. Программа предоставляет различные функции для изучения данных, включая статистические сводки, визуализации и проверку качества данных.

  Установка
Предварительные требования
Python 3.8 или выше

Менеджер пакетов uv (рекомендуется) или pip

Установка зависимостей
bash
# Клонирование репозитория
git clone <your-repository>
cd homeworks/HW03/eda-cli

# Установка зависимостей через uv
uv sync

# Или через pip
pip install -e .
  Использование
Основные команды
1. Общий обзор данных
Показывает основные характеристики набора данных: количество строк, колонок и краткую информацию о каждой колонке.

bash
# Базовый вызов
uv run eda-cli obzor data/example.csv

# С указанием разделителя
uv run eda-cli obzor data/data.csv --razdelyatel ";"

# С указанием кодировки
uv run eda-cli obzor data/data.csv --kodirovka "windows-1251"
2. Показать начало файла
Показывает первые N строк данных (новая команда, добавлена в рамках дополнительного задания).

bash
# Показать первые 5 строк (по умолчанию)
uv run eda-cli nachalo data/example.csv

# Показать первые 10 строк
uv run eda-cli nachalo data/example.csv --kolichestvo-strok 10
3. Полный отчет
Генерирует комплексный отчет со всеми визуализациями и таблицами.

bash
# Базовый отчет
uv run eda-cli otchyot data/example.csv

# Отчет с кастомными параметрами
uv run eda-cli otchyot data/example.csv \
  --papka-dlya-otchyota "my_report" \
  --zagolovok "Мой анализ данных" \
  --maks-gistogramm 10 \
  --minimalnaya-dolya-propuskov 0.15
  Параметры команды otchyot
Параметр	Описание	По умолчанию
--papka-dlya-otchyota	Папка для сохранения отчета	otchyoty
--razdelyatel	Разделитель в CSV файле	,
--kodirovka	Кодировка файла	utf-8
--maks-gistogramm	Максимальное количество гистограмм	6
--zagolovok	Заголовок отчета	"Отчёт анализа данных"
--minimalnaya-dolya-propuskov	Порог доли пропусков	0.1

  Новые эвристики качества данных
В рамках задания были добавлены 3 новые эвристики для оценки качества данных:

Проверка на константные колонки - выявление колонок, где все значения одинаковы

Обнаружение подозрительных ID - проверка уникальности идентификаторов

Анализ нулевых значений - поиск колонок с большим количеством нулей

  Новая команда CLI
Реализована дополнительная команда nachalo для просмотра начала файла, что упрощает первичный осмотр данных.

📝 Пример полного рабочего процесса
bash
# 1. Смотрим общую информацию о данных
uv run eda-cli obzor data/moi_dannie.csv

# 2. Смотрим первые 10 строк
uv run eda-cli nachalo data/moi_dannie.csv --kolichestvo-strok 10

# 3. Генерируем полный отчет с кастомными параметрами
uv run eda-cli otchyot data/moi_dannie.csv \
  --papka-dlya-otchyota "analiz_avtomobilej" \
  --zagolovok "Анализ автомобилей 2024" \
  --maks-gistogramm 8 \
  --minimalnaya-dolya-propuskov 0.05

# 4. Открываем сгенерированный отчет
open analiz_avtomobilej/otchyot.md

Автоматическое создание директорий - программа сама создает необходимые папки для отчетов

Обработка ошибок - корректная обработка проблем с загрузкой файлов и нестандартных форматов

  Советы по использованию
Для больших файлов - используйте параметр --maks-gistogramm для ограничения количества графиков

При проблемах с кодировкой - попробуйте --kodirovka "cp1251" или --kodirovka "ISO-8859-1"

Для TSV файлов - используйте --razdelyatel "\t"

Для экспорта результатов - все таблицы сохраняются в CSV формате, который можно открыть в Excel
